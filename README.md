## What is FaceTracer?

Real reverse image search tool with anime tracking via Trace.moe

## Features

- Real APIs: Trace.moe, SauceNAO, IQDB, 3DAnimeSearch
- Upload to freeimage.host/catbox for stable hosted URL
- 11 stable non-expiring search links (Google Lens, TinEye, Yandex, Bing, etc.)
- Anime/manga episode tracking with similarity scores
- No fake social media links
- Zero config, no API keys needed

## Installation

```bash
git clone https://github.com/b0dj0x/FaceTracer.git
cd FaceTracer
pip install -r requirements.txt
```

## Usage

```bash
python3 facetracer.py search image.jpg
python3 facetracer.py anime image.jpg
python3 facetracer.py osint image.jpg
```
